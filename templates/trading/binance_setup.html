Binance Demo & Futures Setup Guide

Step-by-step instructions to create a Binance Demo account, activate Futures trading, and connect API keys to StockGame.

Dashboard Accounts Binance Setup
1

Create / Sign In to a Binance Demo Account

  1. Open https://demo.binance.com in your browser.
  2. Click Log In (or Register if you don't have a Binance account yet) and sign in.
  3. Once inside Demo Trading, Binance gives you virtual funds (e.g., 5,000 USDT) in a simulated environment — no real funds are used or at risk.
Tip: Demo Trading keys from demo.binance.com are separate from live binance.com keys and connect to Binance's Demo Futures endpoint (demo-fapi.binance.com).
2

Activate Futures Trading & Fund Your Futures Wallet

  1. On demo.binance.com, go to Futures → USDⓈ-M Futures from the top navigation bar.
  2. If prompted to open/activate a Futures account (or complete a quick Futures quiz), accept and activate it.
  3. Transfer USDT from Spot to USDⓈ-M Futures:
    • By default, Demo funds often sit in your Spot wallet, leaving your Futures balance at $0.00.
    • Go to Assets / Wallet → Transfer, set From: Fiat and Spot → To: USDⓈ-M Futures, select USDT, and transfer your desired amount (e.g., 5000).
  4. Accept TradFi-Perps Agreement (Required for Stock/ETF Perpetuals):
    • If you plan to trade stock/ETF perpetuals like NVDAUSDT, TSLAUSDT, QQQUSDT, or SOXLUSDT, open one of those pairs in the Demo Futures UI and accept the TradFi-Perps agreement popup once.
    • Without accepting this agreement in the UI, API orders on stock perpetuals fail with APIError(code=-4411): Please sign TradFi-Perps agreement contract fapi.
3

Generate Demo API Key & Secret

  1. On demo.binance.com, click your Profile icon → API Management.
  2. Click Create API → choose System generated (HMAC), give it a label (e.g., stockgame-demo), and complete verification.
  3. Copy and save both the API Key and Secret Key immediately (Binance hides the Secret Key after you leave the page).
  4. Click Edit restrictions on the new key and ensure these permissions are checked:
    • Enable Reading (always required)
    • Enable Futures (required to read Futures balances/positions and place Futures orders)
  5. Click Save to apply the permissions.
Important: If you enable Enable Futures after creating the key, remember to click Save at the top of the API Management card.
4

Connect the Account in StockGame & Verify

  1. Open the Accounts page and click + Add Account.
  2. Set Environment to Binance Demo (demo.binance.com), Market to USDⓈ-M Futures, and choose your Futures Leverage (e.g., 5).
  3. Paste your API Key and API Secret (secrets are encrypted at rest before saving).
  4. Click Save Account, then click Test API on the account card. You should see: OK: Demo Futures connected. Available USDT: $....
5

Bot Qty & Execution Checklist

  • Paper vs. Demo vs. Live: Every trade is always recorded in the database (Paper). Checking Demo on a bot also sends the order to your Binance Demo account; checking Live sends it to Live.
  • Minimum Order Notional (-4164): Binance Futures enforces a minimum order notional (e.g., $50 USDT on BTCUSDT). For BTCUSDT, set Qty to at least 0.001 (~$60 notional) so orders aren't rejected.
  • Supported Demo Symbols: Default preset symbols verified on Demo Futures are BTCUSDT, SOXLUSDT, QQQUSDT, ETHUSDT, NVDAUSDT, and TSLAUSDT.
